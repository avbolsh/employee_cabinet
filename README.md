# Кабинет сотрудника (MVP)

Личный кабинет сотрудника на Django (аналог «1С:Кабинет сотрудника»).  
MVP включает:

- аутентификацию с двухфакторным входом (пароль + TOTP-код из приложения-аутентификатора, напр. Google Authenticator, Authy),
- профиль сотрудника,
- просмотр расчётных листов,
- подачу и просмотр заявок на отпуск
